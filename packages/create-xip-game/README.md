# create-xip-game

Scaffold a new [Xip](https://xipjs.dev) game project in seconds.

## Usage

```bash
# npm
npx create-xip-game my-game

# pnpm
pnpm create xip-game my-game

# yarn
yarn create xip-game my-game

# bun
bunx create-xip-game my-game
```

Then:

```bash
cd my-game
npm install
npm run dev
```

## What you get

A ready-to-run Vite + React + TypeScript project with:

- `xipjs` pre-installed
- A working example game (platformer with physics, input, camera)
- `vite.config.ts` configured for canvas games
- `tsconfig.json` with strict mode
- Dev server on `localhost:5173`
